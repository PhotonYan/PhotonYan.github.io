# Code Of Conduct

This project is a personal academic website. Contributions and discussions should stay respectful, relevant, and focused on improving the site.

## Expected Behavior

- Use clear and respectful language.
- Assume personal profile, publication, curriculum, and academic-history content belongs to the site owner.
- Give concrete feedback when reporting bugs or proposing edits.
- Keep discussions focused on the website, documentation, content quality, accessibility, or deployment.

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Misrepresenting the site owner's identity, affiliations, publications, or academic record.
- Spam, unrelated promotion, or disruptive issue/PR activity.

## Enforcement

The maintainer may edit, close, reject, or remove contributions that are unrelated, inaccurate, unsafe, or inconsistent with this code.

To report conduct issues connected to this site, contact `photonyan@stu.pku.edu.cn`.
